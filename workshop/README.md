## Public versus restricted

This repository and this branch are public. A branch is not a privacy boundary. Keep private conversations, personal histories, restricted attachments, unclassified packages and private-repository evidence out of this branch. Even source metadata needs disclosure review.

Complete originals belong in approved custody. A public summary cannot substitute for an unavailable body. Comprehensive historical recovery does not require comprehensive public disclosure.

## Receive once; explain once; assign work once

Preserve each original contribution and its attachments. Record origin, source date or unknown date, intake date, location, content identity, custody and access class. The receiver handles classification; the contributor need not learn the filing system first.

A correction is a linked witness, not a silent rewrite. Repeated delivery is not independent corroboration. Update the current topic account when understanding changes. Create or update one owning task only for a real unresolved outcome. Testimony can be valuable without generating a task or product edit.

The catalogue identifies sources; the dossier explains current understanding. Linear coordinates work rather than maintaining another source archive. A tool mirror represents the same work identity, not a second assignment.

## Review and handoff

Pin branch, commit, bodies, scope, writer and receiving owner before a change. Use one active writer for the agreed scope; reread remote targets and refuse unexpected collisions. This document does not establish a technical lock or assign another steward.

For each file, identify purpose, audience, applicable authority, readers and dependencies. Preserve the original and provide the complete proposed final body. Record preservation requirements, actual reviewer and receiving disposition. `NO_CHANGE` is valid. Review files individually; release only dependency-complete changes.

Workshop documentation receives proportionate review. Product contracts still govern product changes. Do not automatically import another project's offices, terminology or gates. Author checks are not independent review.
